## Audience-Specific Drafts

### Professional / Technician Draft

Screen symptom categories:
- Torn mesh
- Loose spline symptom (retention concern only)
- Bent frame
- Missing screen
- Poor fit at frame/opening
- Insect-entry complaint

Documentation approach:
- Capture size/location and symptom severity
- Note whether associated window operation concerns are also present
- Separate screen-only issue from broader window/glass concerns

No step-by-step repair guidance is included.

### Owner / Admin Draft

This low-risk candidate supports:
- Fast dispatch classification for screen-only jobs
- Cleaner quote packaging for mesh/frame/fit service opportunities
- Consistent customer-safe communication
- Reduced callback risk through clear scope notes

### Dispatcher-Safe Draft

Intake checklist:
1. Which screen is affected and where?
2. Symptom category (torn mesh, loose retention, bent frame, missing, poor fit, insect complaint).
3. Is there any related glass damage or opening safety concern?
4. Safe photo request from normal standing location.

Route screen-only requests to standard service queue; escalate if glass/safety concern is present.

### Customer-Safe Draft

Screen issues are usually documented by condition and fit symptoms. A service visit can confirm scope and provide options for replacement or adjustment services. If glass is damaged nearby, request priority escalation.

### Public-Safe Draft

Screen service is typically a low-risk maintenance scope when limited to mesh/frame/fit concerns. Public messaging should stay high level and avoid repair procedures.

## Candidate Claim

Proposed candidate low-risk baseline for window screen concerns:
1. Standard symptom categories for intake and reporting.
2. Clear distinction between screen-only scope and safety-sensitive window/glass concerns.
3. Quote/service opportunity framing without technical repair steps.
4. Business value for dispatch speed, quote quality, customer communication, and liability control.

## Escalation Rule

Escalate when:
- Broken/cracked glass is reported near screen opening
- Opening cannot be safely operated
- Customer asks for compliance/warranty/manufacturer/legal conclusions
