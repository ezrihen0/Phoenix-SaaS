# Gas Fireplace — Manufacturer Manual Rule (V1)

## Purpose

Make manufacturer instructions and applicable local code the controlling authority for all technical decisions, clearances, parts, and operation statements.

## When to use this knowledge

- Any question about clearances, parts, adjustments, operation limits, or “is it safe?”
- Example: “Can I promise the customer it is safe now?”

## Safe field checks

- Locate nameplate; obtain correct manual version (brand + model + serial).
- Follow company procedure for manual lookup (office database, manufacturer portal — not random web PDFs unless verified).
- Work only within steps explicitly allowed for your role in that manual.

## What evidence to collect

- Manual reference (document ID, revision date) when used for guidance.
- Screenshots or citation of manual section for office record (not customer-facing code book dumps).

## What not to say

- “In general, all fireplaces need…” when model-specific rules differ.
- Clearance or pressure numbers from memory.
- “It’s safe” without scope-appropriate testing defined in manual and qualified personnel where required.

## Customer explanation language

- “We go by your unit’s manufacturer instructions and local gas code — that’s what protects your home and warranty.”
- “I can’t promise safety as a blanket statement; I can document what we did per the manual today.”

## Report-safe wording

- “Service performed per [manufacturer] installation/operation manual section [reference if recorded]. Local code authority having jurisdiction applies for compliance determinations.”
- “No warranty or safety certification implied beyond documented scope.”

## Escalation conditions

- Manual unavailable, conflicting with field conditions, or requires engineering: escalate to supervisor / qualified gasfitter.
- Customer requests work outside manual: decline and document.

## Sales/service opportunity if applicable

- Sell documented maintenance labeled as “manufacturer-scheduled service” when manual specifies intervals.
- Manual-driven upgrade parts only after compatibility verification.
